## 🎮 Sobre o Projeto

**TechGirls Challenge** é um jogo educativo interativo desenvolvido para despertar a curiosidade de meninas de 13 a 17 anos sobre o fascinante mundo da tecnologia. Através de perguntas divertidas e desafiadoras, as jogadoras aprendem sobre:

- 💻 **Pensamento Computacional**
- 🤖 **Inteligência Artificial**
- 🔒 **Segurança da Informação**
- 🌐 **Programação e Desenvolvimento Web**
- 📊 **Machine Learning**

## ✨ Características

- 🎨 **Design moderno e atrativo** - Cores vibrantes e animações suaves
- 📝 **8 perguntas educativas** - Conteúdo selecionado para o público adolescente
- 🏆 **Sistema de pontuação** - Feedback instantâneo e gamificação
- 💡 **Explicações detalhadas** - Cada resposta vem com uma explicação educativa
- 📱 **Responsivo** - Funciona perfeitamente em celulares, tablets e computadores
- 🎯 **Feedback visual** - Indicação clara de respostas certas e erradas

## 🖥️ Demonstração

![Demonstração do Jogo](https://via.placeholder.com/800x400?text=TechGirls+Challenge+Demo)

### Como Jogar:
1. Leia cada pergunta com atenção
2. Escolha a resposta que você acha correta
3. Receba feedback imediato e aprenda com as explicações
4. Acumule pontos a cada acerto
5. Complete todas as perguntas e veja sua pontuação final!

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura do jogo
- **CSS3** - Estilização, animações e design responsivo
  - Gradientes personalizados
  - Animações CSS
  - Layout flexível
- **JavaScript** - Lógica do jogo
  - Manipulação do DOM
  - Sistema de pontuação
  - Feedback interativo

🎯 Objetivo

A jogadora assume o papel de uma detetive digital que precisa:

identificar golpes online,
reconhecer imagens feitas por IA,
criar senhas seguras,
proteger dados digitais,
resolver desafios tecnológicos.

O jogo ensina conceitos de:

Segurança da Informação
Inteligência Artificial
Pensamento Computacional
Cidadania Digital

de forma leve, visual e interativa.

🕹️ Funcionalidades

✅ Sistema de pontuação
✅ Timer por fase
✅ Explicações educativas
✅ Feedback visual de acerto/erro
✅ Interface responsiva
✅ Jogo 100% em HTML, CSS e JavaScript
✅ Fácil de hospedar gratuitamente

📸 Tema do jogo

Cyber Detective Girls mistura:

investigação digital,
estética moderna,

Tudo pensado para tornar tecnologia mais divertida e acessível para adolescentes.
